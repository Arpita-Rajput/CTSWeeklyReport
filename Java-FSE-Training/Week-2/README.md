# Java FSE Training - Week 2

This folder contains the Week-2 mini-projects for the Java Full Stack Engineer training.

Projects included:
- Spring-Core-Maven: Employee Management with Spring Core DI
- Spring-Data-JPA: Student CRUD with JPA and REST APIs
- Hibernate-CRUD: Product Management with Hibernate ORM

Each mini-project is independent and contains its own pom.xml, src/, and application.properties.
